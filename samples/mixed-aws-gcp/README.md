# Mixed AWS + Google Cloud plan

A small hand-written plan (`plan.json`) with an AWS VPC, subnet and instance,
and a Google Cloud network, subnetwork, VM and bucket. It is not generated by
`terraform`; it has the fields the viewer reads, in the shape `terraform show
-json` writes them.

`tools/check-layout.js` and `tools/check-parse.js` include it, so a change to
how several providers are drawn together shows up as a baseline diff. Open it
with **Load plan json** to see one cloud box per provider.
